# Dialogue Builder

Visual Ink editor for Cacophobia. Game text is English. Export is `.ink` only.

Open `/builder.html` while `npm run dev` is running, or `npm run builder`.

**Save to game** writes `content/story/story.ink` and `content/story/levels/level-N.ink`. The game reloads from those files.

Full controls: facts, levels, knots, lines, choices, events, `# sound` / `# shake` / `# go` / `# level` / `# quit`, set-fact, and conditions. See the root `README.md` section **Write dialogue**.
